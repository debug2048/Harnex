# Feedback and contributions / 反馈与贡献

Harnex currently accepts external bug reports and suggestions through [Issues](https://github.com/debug2048/Harnex/issues/new/choose). Pull request creation is limited to repository collaborators. Please discuss a proposed change in an Issue before preparing a patch; accepting an Issue does not promise implementation or a delivery date. The [Apache-2.0 license](LICENSE) governs use, modification and redistribution of the source.

Use the bug form for installation, Runtime or client failures. Include the Harnex version, OS/CPU architecture, client, installation method, minimal reproduction, expected/actual behavior and sanitized logs. For a suggestion, describe the user problem and a concrete example. Check existing Issues first.

Remove API keys, tokens, passwords, private endpoints, personal information and confidential project content from logs or screenshots. For a vulnerability, follow [SECURITY.md](SECURITY.md) instead of posting exploit details publicly.

当前对外通过 [Issue](https://github.com/debug2048/Harnex/issues/new/choose)接受问题与建议，PR 仅限仓库协作者。准备补丁前请先讨论问题和范围；接受反馈不代表承诺实现或交付日期。源码的使用、修改与再分发遵循 [Apache-2.0](LICENSE)。

报告故障时请提供版本、操作系统/CPU、使用入口、安装方式、最小复现步骤、预期与实际结果，以及脱敏日志。功能建议请描述具体场景和希望解决的问题。提交前先搜索已有 Issue；不要上传密钥、私有地址、个人信息或机密项目内容。安全漏洞请按[安全政策](SECURITY.md)私密报告。
